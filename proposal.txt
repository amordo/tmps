Parallel Programming with Off-Heap Memory in Scala Native
Background. The Scala programming language is known for excellent support for concurrent and distributed programming, for example, using futures or actors. Regular Scala code depends on garbage collection for automatic memory management. However, for certain performance-critical systems and applications the efficiency loss and increased latency of garbage collection is not acceptable [1].

This project aims to explore the use of off-heap memory for parallel programs compiled using the Scala Native [2] compiler in order to avoid the use of garbage collection. The main hypothesis is that parallel programs processing significant amounts of data (for example, stream processing) can benefit substantially from the higher efficiency of off-heap memory.

Highlight: This MSc thesis contributes to a research paper to be completed in Summer/Fall 2026, in collaboration with a PhD student (safety of off-heap memory zones via types). The project is also planned to be presented at a leading Scala conference.

Project goals and plan:
Design and implement a library for parallel collections (with an API similar to [3,4]) whose memory is allocated in off-heap zones. (Scala Native already provides support for off-heap zones.)
Design and implement a suite of representative benchmark programs to evaluate the performance of off-heap parallel collections compared to on-heap parallel collections.
Gather and curate a selection of datasets to use for the experimental evaluation. The datasets of the DEBS Grand Challenges [5] can serve as a starting point.
